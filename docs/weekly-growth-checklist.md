# Weekly Growth Checklist

Use this once per week (10-15 minutes) to improve enquiries and bookings without overcomplicating the platform.

## 1) Open the dashboard metrics

- Go to Django Admin.
- Review the Funnel Summary card on the admin home.
- Note these numbers:
  - Card clicks
  - Availability clicks
  - Enquiry submits
  - Avail -> enquiry rate

## 2) Compare momentum

- Check Last 24h submits vs Prev 24h.
- Mark one status:
  - Up
  - Flat
  - Down

## 3) Spot weak categories

- Review vendor-type split (Musicians / Caricaturists / Photographers).
- Identify the weakest conversion rate this week.
- Pick one category to improve first.

## 4) Look at raw event patterns

- Open Bookings > Funnel events in admin.
- Scan for unusual patterns:
  - High clicks but low submits
  - Drop in multi-enquiry usage
  - Sudden traffic change on one page path

## 5) Decide one action only

Choose just one change for the next 7 days:

- Improve CTA copy on one page.
- Improve trust text (reviews/process clarity).
- Simplify one form section.
- Improve availability/date messaging.

Keep changes small and measurable.

## 6) Log your weekly note

Record this in a simple note each week:

- Week ending date
- Avail -> enquiry rate
- Best performing vendor type
- Weakest vendor type
- One change made
- Result next week (better/same/worse)

## 7) Rule: avoid overbuilding

- Do not add new major features unless metrics show a clear need.
- Keep testing one focused change at a time.
- If rate is improving, keep the system simple.
